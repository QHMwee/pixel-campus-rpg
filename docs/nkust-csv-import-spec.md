# 高科大（NKUST）CSV 課表匯入規格

## 資料來源與設計原則

高科大官方「課程資料查詢」頁面可依學年學期、校區、學制、科系、年級、星期、節次、科目與教師進行查詢，並列出建工、燕巢、第一、楠梓、旗津及東方等校區。[官方課程資料查詢](https://webap.nkust.edu.tw/nkust/ag_pro/ag202.jsp)

本功能**不會登入、爬取或自動同步校務系統**。使用者需自行將已取得的資料整理或另存為 CSV，再選擇檔案匯入；所有資料只會在預覽確認後寫入目前裝置的課程規劃表。

## 受支援的 CSV 欄位

| Campus Quest 欄位 | 高科大常見標題別名 | 是否必要 | 匯入用途 |
| --- | --- | --- | --- |
| `學年學期` | 學年學期、學期、學年度、開課學期 | 是 | 對應本機規劃的學期文字，例如「115-1」 |
| `科目名稱` | 科目名稱、課程名稱、科目 | 是 | 建立規劃課程名稱 |
| `學分` | 學分、學分數 | 否 | 空白時以 0 顯示並要求使用者在預覽階段補正 |
| `類別` | 課程類別、必選修、修別 | 否 | 支援必修、選修、通識；無法辨識時標示為選修並可修改 |
| `課號` | 課號、科目代碼、課程代碼 | 否 | 僅作為重複偵測與預覽資訊，不會顯示為成績資料 |
| `校區` | 校區、上課校區 | 否 | 僅作為預覽資訊，不會影響 GPA 或畢業學分 |
| `授課教師` | 教師、授課教師 | 否 | 僅作為預覽資訊，不會送往 AI 或計入任何學業指標 |
| `星期` | 星期、上課星期 | 否 | 僅作為預覽資訊；目前不自動建立行事曆時段 |
| `節次` | 節次、上課節次、時間 | 否 | 僅作為預覽資訊；目前不自動建立行事曆時段 |
| `教室` | 教室、上課地點 | 否 | 僅作為預覽資訊 |

> **隱私與資料界線：**學號、姓名、身分證字號、電子郵件、成績、缺曠與選課流水號均不屬於本功能需求。即使 CSV 包含這些欄位，解析器也會忽略，不會儲存或傳送。

## 下載範本欄位順序

```csv
學年學期,課號,科目名稱,學分,課程類別,校區,授課教師,星期,節次,教室
115-1,, ,0,選修,,,,,
```

這一列只有結構，不含任何真實或示範課程資料。使用者可用 Excel、Google 試算表或文字編輯器填寫後另存為 UTF-8 CSV，再從 Campus Quest 匯入。

## 重複處理與確認規則

同一筆「學年學期＋課程名稱」的資料在既有規劃表中已存在時，系統會標示為重複並預設略過。使用者能在預覽階段逐列修改、刪除或確認；匯入只會影響「規劃中」課程，不會新增成績、改變 GPA，也不會把規劃學分視為已完成學分。
