# 職涯能力與專題構想：資料來源

Campus Quest 將職務資料中的典型工作活動轉換為學生能練習、能交付、能放入作品集的能力方向；它不是個別公司職缺或錄取結果的保證。

| 職涯方向 | 對照資料 | 網站採用的能力焦點 |
| --- | --- | --- |
| 前端工程師 | Web Developers | 需求轉譯、互動介面、測試與部署 |
| 資料分析師 | Data Scientists | 資料處理、統計評估、視覺化與報告 |
| 產品經理 | Project Management Specialists（相近職能） | 利害關係人需求、範圍、里程碑、交付與溝通 |
| 研究與深造 | Computer and Information Research Scientists | 問題分析、研究設計、評估與技術寫作 |

> 專題構想以校園情境、公開資料或非敏感資料為優先。蒐集問卷、感測或使用行為資料前，應取得適當同意、去識別化，並遵守課程、學校與研究倫理規範。
