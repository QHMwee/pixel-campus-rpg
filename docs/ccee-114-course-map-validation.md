# 電通系 114 課程地圖驗證紀錄

## 空白起始狀態

在空白的隔離開發預覽開啟「課程規劃」後，電通系完整課程地圖正確呈現 **103 門**官方列示的系專業課程，並提供系必修、大二核心、大一／二專業實習、大三專業實習、職場實習、其他選修、大三核心，以及電腦與資訊、通訊與電子、網路與多媒體等群組篩選。

四個規則卡片正確顯示空白起始缺口：大二核心 3 門／9 學分、大三核心 3 門／9 學分、大一／二專業實習 2 門／2 學分，以及大三專業實習 3 門／3 學分。頁面清楚說明地圖不判斷當期開課，且官方擋修只顯示提醒、不阻擋加入規劃。

在「網路與多媒體」篩選群組中，電腦網路明確標示官方擋修前提為「多媒體與網路導論 ≥ 60 分」；微波元件實習亦在完整地圖中標示「電磁學 ≥ 40 分」。

## 加入與擋修行為

在未建立任何已修成績的隔離預覽中，將「電腦網路」加入規劃後，系統立即建立一筆 `115-2`、3 學分、專業選修的規劃資料，規劃學分更新為 3，並把該課按鈕改為「已在規劃中」。同時頁面顯示「多媒體與網路導論 ≥ 60 分」的官方擋修提醒；課程仍成功加入，沒有被阻擋，也沒有新增已完成課程或改動 GPA。

驗證完成後已清除隔離開發預覽的 localStorage 並強制重新載入。頁面重新顯示已完成學分 0、目前規劃學分 0 與空白規劃表，確認測試用「電腦網路」沒有殘留；使用者實際裝置的本機資料不受影響。

## 智慧任務推薦

在空白資料狀態的「智慧任務」頁面，推薦區明確標示採用電通系 114 官方課程地圖，並優先補足核心與專業實習最低門檻。推薦顯示大三專業實習「視窗程式應用設計實習」、大三核心「演算法」與大一／二專業實習「物件導向系統分析實習」；同時將「電腦網路」與「微波元件實習」列為待解鎖進階課程，分別指出缺少多媒體與網路導論、電磁學的先修條件。
