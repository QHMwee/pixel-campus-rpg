# 電通系 114 課程地圖規則

## 採用範圍

本文件只依據高科大電腦與通訊工程系**四技 114 學年度入學**課程結構規劃表，作為 Campus Quest 的「可規劃課程」與畢業條件檢查依據。課程地圖不表示當期一定開課；選擇課程只會寫入本機「規劃中」資料，不會變更 GPA、已完成學分或成績。[1]

## 官方畢業與選修邊界

| 檢查項目 | 規則 | 課程地圖的處理 |
| --- | --- | --- |
| 畢業總學分 | 128 學分 | 使用既有總畢業目標。 |
| 系必修 | 51 學分、21 門 | 顯示於課程地圖，可加入規劃。 |
| 系專業選修 | 49 學分 | 所有官方列示系選修皆可加入規劃，累計於專業選修規劃檢查。 |
| 大二核心 | 至少 3 門、9 學分 | 以大二核心標籤分組並另行檢查。 |
| 大三核心 | 至少 3 門、9 學分 | 以大三核心標籤分組並另行檢查。 |
| 大一、大二專業實習 | 至少 2 門、2 學分 | 以專業實習標籤分組並另行檢查。 |
| 大三專業實習 | 至少 3 門、3 學分 | 以專業實習標籤分組並另行檢查。 |

## 官方明列的擋修

| 欲規劃課程 | 檢查前提 | 系統行為 |
| --- | --- | --- |
| 微波元件實習 | 已修畢電磁學，且成績至少 40 分 | 仍允許加入規劃；標示為「擋修提醒」直到前提滿足。 |
| 電腦網路 | 已修畢多媒體與網路導論，且成績至少 60 分 | 仍允許加入規劃；標示為「擋修提醒」直到前提滿足。 |

> 不把官方未列示的建議學期、推測先修關係或當期開課狀態當作擋修條件。

## 課程群組

課程地圖包含官方列示的系必修、大二核心、大三核心、大一／大二與大三專業實習，以及三個系專業選修領域：電腦與資訊、通訊與電子、網路與多媒體。學院共同與跨領域課程另列為可規劃的延伸選項，且提示其認列邊界。
