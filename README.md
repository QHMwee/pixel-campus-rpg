# Campus Quest｜大學生涯冒險誌

Campus Quest 是一個以像素風 RPG 呈現的大學生涯規劃工具。它協助使用者在**目前裝置本機**管理成績、固定 4.3 制 GPA、畢業學分、課程規劃、職涯建議、專題、證照考試專案與成就進度。

## 主要功能

| 模組 | 功能 |
| --- | --- |
| 學業紀錄 | 手動管理課程、計算學期／累計 GPA、追蹤歷年趨勢與學分缺口。 |
| 成績單匯入 | 支援 CSV、TSV 與文字型 PDF 轉 CSV；所有列均可在確認前修改或刪除。 |
| 四年規劃 | 課程規劃、CSV／.ics 匯出、Notion 合併 CSV 與職涯導向選課建議。 |
| 證照專案 | 可建立、調整與刪除多益、CPE 等本機考試規劃。 |
| 高科大課表 CSV | 支援高科大常見欄位標題、學期正規化、逐列預覽與重複略過；匯入只新增「規劃中」課程。 |
| 行動使用 | 提供 PWA 安裝提示與 Android APK 下載入口。 |

> **資料隱私：**成績、課程規劃、專題與證照資料只保存在各瀏覽器或 WebView 的 `localStorage`，不會自動跨裝置同步。高科大課表匯入不對應或保存學號、姓名、成績、缺曠與選課流水號。

## 本機啟動

```bash
pnpm install
pnpm test
pnpm dev
```

測試使用 Vitest；目前專案包含學業計算、成績匯入、PDF 轉換與高科大 CSV 課表解析的測試覆蓋。

## 高科大 CSV 課表匯入

在「課程規劃」頁選擇 **匯入高科大 CSV**，可下載空白範本或貼上／上傳 UTF-8 CSV、TSV。系統預期學年學期、科目名稱與學分欄位；支援校區、教師、星期、節次與教室等額外欄位，但僅將必要的規劃欄位寫入本機。匯入的課程不會影響 GPA、已完成學分、能力或 XP。

高科大的官方課程資料查詢頁提供學年學期、校區、學制、科系、年級、星期、節次、科目與教師的查詢條件。[1]

## 來源與限制

本儲存庫不包含 `node_modules`、本機日誌、快取、環境變數或使用者本機資料。Android WebView 原始專案與 debug APK 位於獨立建置環境，不應以未驗證的副本納入此網站來源庫。
